# Agent Entry Point

Before executing any prompt in this repository, read these files in order:

1. `.agents/AGENTS.md` — mandatory working rules and environment
2. `.agents/CONTEXT.md` — project structure, stack, data flow, known issues
3. `.agents/TASKS.md` — the agreed task plan

These three files are the source of truth for how work is done here.

The Laravel backend lives in `backend/` and has its own docs at
`backend/.agents/AGENTS.md`. Read those before changing backend code.
